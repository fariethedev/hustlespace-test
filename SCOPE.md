# Prototype scope

HustleUP Test is a static concept demonstrator with a local read-only mock API,
not a marketplace service.

## Included

- Fictional seller cards, listings, categories, and prices.
- Search and category filtering performed in the browser.
- A local-only preview panel that demonstrates a possible service-request flow.
- A mock backend that serves the fictional catalog and health status only.
- Temporary UI state held only in JavaScript memory until the page is closed.

## Explicitly excluded

- User accounts, authentication, and profiles tied to real people.
- Names, email addresses, phone numbers, addresses, payment details, or other
  personal data fields.
- Databases, authentication, cookies, analytics, and any API write endpoint.
- Real bookings, payments, payouts, messaging, notifications, or email.
- File uploads, camera access, location access, and third-party integrations.
- Production deployment or use with real customers.

All people, businesses, listings, reviews, and prices shown in the interface are
fictional placeholders for product discussion only.
